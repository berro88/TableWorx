# TableWorx website

Marketing site for TableWorx — KDS, Waiter App, and Customer App for independent restaurants.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js App Router, TypeScript, CSS aligned to the August 2026 UX/UI brief (warm paper, teal contrast, persistent demo CTA).

Brand and design source files live in `brand/`.
